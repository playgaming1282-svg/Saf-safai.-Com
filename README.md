## Before publishing
- Open `js/main.js` and replace `919999999999` with your real WhatsApp number (country code, no + or spaces).
- Replace the phone number in the same file with your actual call number.
- Update service areas, opening hours and any service inclusions you want to confirm.
- Images use externally hosted Unsplash image URLs and need internet access.
- Pricing is filled in only for Flat Cleaning based on the rates provided. Other services say “Price on request” to avoid inventing prices.

## Publish on GitHub Pages
1. Extract the ZIP.
2. Upload all files/folders to the root of your GitHub repository.
3. In repository Settings → Pages, choose deploy from branch, select `main` and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.

This project is static and does not need a server or build step.
